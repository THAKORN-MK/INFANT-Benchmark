# ข้อมูลสำหรับ Benchmark

โฟลเดอร์นี้ยังไม่มี dataset และโครงการยัง **ไม่พร้อมฝึก** อย่าย้ายหรือแก้ไฟล์ใน `D:\INFANT CRY` เพื่อจัดข้อมูลให้โครงการนี้

หากมีชุดข้อมูลต้นฉบับของบทความและได้รับอนุญาตให้ใช้ กรุณาเตรียมไฟล์เสียงพร้อม metadata, README ของ dataset และเอกสารที่ระบุ version / ที่มาของแต่ละ tier แยกไว้ โดยยังไม่จำเป็นต้องคัดลอกข้อมูลใดเข้าที่นี่ในตอนนี้

อย่าสร้าง infant ID จากชื่อไฟล์หรือ clip ID ด้วยการคาดเดา และอย่าเปลี่ยน label จากชื่อไฟล์เพียงอย่างเดียว รายละเอียดการตรวจสอบอยู่ใน `docs/replication_audit.md`
